Privacy Policy

Last updated: October 12, 2026

This policy covers the Atlas of Why website and the "Atlas of Why publisher" application, a private tool used only by the owner of the Atlas of Why YouTube channel.

What data the application uses

The application uses YouTube API Services, with the channel owner's authorization, to: upload the channel's own videos; edit their titles, descriptions, thumbnails, playlists and publishing schedule; and read the channel's own YouTube Analytics reports.

It does not collect, access or process data of any other YouTube user or visitor. This website does not use cookies, analytics or trackers.

Storage and sharing

OAuth tokens are stored as encrypted secrets and are never shared. Analytics figures are used only to plan future videos on the channel. No data is sold, shared with third parties or used for advertising.

YouTube and Google

This application uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service. See the Google Privacy Policy. You can revoke the application's access at any time at Google security settings.

Deletion

Revoking access stops all use immediately; stored tokens are then deleted. Any stored API data is deleted within 30 days, or on request.
